# 个人工作台 · Personal Workbench

一个**零依赖、零构建**的纯前端单页工作台 ——
把每天要看的东西放在一屏里：今天该做什么、打卡打到哪了、这个月花了多少。

**没有账号、没有后端、没有框架、没有 npm。** 双击 `index.html` 就能用，数据全部存在你自己的浏览器里。

> **在线体验**：https://personal-workbench-89221.app.workbuddy.host/
> 打开即用，不需要注册。你的数据只存在**你自己**浏览器里，和别人的互不相通。

---

## 项目背景

起因很简单：不想为了"记一下今天要做的事"去装一个 App、注册一个账号、再忍受一堆推送。
于是从零写一个只属于自己的工作台，顺便把前端这件事学明白 ——
HTML / CSS / JS 各自负责什么、浏览器按什么顺序加载、数据怎么存、状态怎么不打架。

给自己定了个 21 天的小目标，一天推进一步。**这个仓库就是那个过程的完整记录**：
不只是成品代码，还包括需求文档、开发规范、决策记录，以及一路上踩过的坑。

所以这里**没有炫技**：没有框架、没有构建工具、没有依赖树。
全部业务代码是 9 个文件，你可以一个个读完。

## 功能

| 模块 | 能做什么 |
|---|---|
| **今日看板** | 日期与时段问候；三张汇总卡（待办进度 / 今日收支 / 打卡达标）；内嵌番茄钟；下方「本日待办」「打卡一览」两块 |
| **打卡** | 打卡项自己增删改（名称 / 类型 / 周期 / 目标次数）；点 `+1` 推进、点 `−1` 纠正；每日按自然日重置，每周从周一算起 |
| **待办** | 三个 Tab（本日 / 本周 / 本月）；**每条一个进度**（0 / 20 / 40 / 60 / 80 / 100%，点档位推进，再点当前档位退回 0%）；优先级高 / 中 / 低；截止日期；可关联一条笔记 |
| **快速笔记** | 写完提交、自动记录时间；提交后不可编辑（写错只能删除重录） |
| **记账 + OCR** | 收入 / 支出分类记账；识别账单截图 → 弹出确认卡 → **确认后**才入账；不保存原图 |
| **快捷入口** | 常用网站一键打开；常用文本一键复制 |
| **番茄钟** | 专注 25 / 休息 5，圆环倒计时 + 开始 / 暂停 / 重置。纯内存，刷新即归零 |
| **数据管理** | 导出 / 导入 JSON、清空本机数据 |

完整规则见 [`PRD.md`](PRD.md)。

## 怎么跑起来

### 只想用

打开 `index.html`，或者用上面的在线链接。

### 想改代码

⚠️ **开发时不要用 `file://`** —— 剪贴板 API 和 OCR 的 worker 在 `file://` 下会被浏览器限制。
起一个本地静态服务器（不需要装任何依赖）：

```bash
# Python 自带，最省事
python -m http.server 8777

# 或者用 Node
npx serve .
```

然后访问 <http://127.0.0.1:8777/>

### 想部署

任何静态托管都可以（GitHub Pages / Vercel / Netlify / 对象存储 / Nginx…）：
**把整个目录传上去即可，没有构建步骤。**

三个必须注意的点：

1. **改了 `css/` 或 `js/` 里的任何文件，要同步改 `index.html` 里那 9 处 `?v=` 版本号。**
   原因见 [`AGENTS.md`](AGENTS.md) 的「静态资源与缓存」—— 不加版本号时，浏览器会拿
   *旧 CSS 配新 HTML*，症状是每个 SVG 图标都变成一个大黑块。
2. **换域名 = 换 origin = 老数据不会跟过去。** 迁移办法：旧地址「导出 JSON」→ 新地址「导入 JSON」。
3. **静态托管通常会把整个目录发出去。** 别把私密文件放在项目根下
   （本仓库的 [`.gitignore`](.gitignore) 已经排除了 WorkBuddy 的工作记忆与本地标记文件）。

## 目录结构

```
.
├── index.html          单页骨架：左侧导航 + 看板 + 各模块页 + 详情表单
├── css/
│   └── style.css       全部样式。顶部两个变量块（浅色 / 深色）是唯一配色来源
├── js/
│   ├── storage.js      localStorage 的唯一出入口：读写 + 兜底 + 导出导入
│   ├── todo.js         待办：数据、优先级、进度档位、排序
│   ├── notes.js        快速笔记
│   ├── links.js        快捷入口（网站 + 常用文本）
│   ├── habits.js       打卡：配置、周期计算、进度
│   ├── ledger.js       记账：金额（整数分）、分类、统计
│   ├── ocr.js          账单 OCR（Tesseract.js，按需加载）
│   └── app.js          启动、导航、各模块渲染与事件绑定
├── PRD.md              产品需求文档
├── AGENTS.md           开发规范（改代码前先读这个）
├── PROJECT.md          项目状态与决策记录
├── LICENSE             MIT
└── README.md
```

**脚本加载顺序固定**：`storage.js` → 各业务模块 → `app.js`。
只有 `app.js` 负责 `init()`，业务模块只暴露函数。
（违反这条的典型症状：同一次点击触发多次响应、看板数字翻倍，且控制台不报错。）

## 数据存在哪

全部在浏览器 `localStorage`，用 7 个 key，前缀统一是 `workbench.`：

| key | 内容 |
|---|---|
| `workbench.todos` | 待办 |
| `workbench.notes` | 快速笔记 |
| `workbench.links` | 常用网站 |
| `workbench.snippets` | 常用文本 |
| `workbench.ledger` | 记账记录 |
| `workbench.habits` | 打卡项与打卡记录 |
| `workbench.meta` | 显示偏好（主题、昵称）与初始化标记 |

**导出**出来是一份 JSON：

```json
{ "schemaVersion": 1, "exportedAt": "2026-09-24T...", "data": { "todos": [], "...": [] } }
```

**没有任何服务端**，所以这份 JSON 是唯一的备份手段。

## 几个刻意的设计选择

| 选择 | 为什么 |
|---|---|
| **零依赖、零构建** | 打开就能用、十年后还能跑。没有 `node_modules`，也就没有升级地狱 |
| **数据存 localStorage，不做后端** | 不需要账号、不产生服务器成本、断网也能用。代价见下方「已知边界」 |
| **金额用「分」的整数存** | `8650` 表示 ¥86.50。浮点数存钱迟早会差几分 |
| **用户输入一律 `textContent`，不用 `innerHTML`** | 除了注入风险，文字里含 `<` 或 `&` 时也会渲染错乱 |
| **改数据结构时优先"缺字段按默认值处理"** | 这样老数据不用迁移、用户不用重新导入。待办的 `priority` 和 `progress` 都是这么加的 |
| **`done` 由 `progress` 派生，而不是两个字段各存一份** | 两个真相来源迟早打架，会出现"进度 100% 却显示未完成" |
| **番茄钟纯内存、不落库** | 它是一次性的节拍器，不是需要统计的数据 |

## 踩过的坑（这一节大概最有用）

| 现象 | 根因 |
|---|---|
| 线上每个图标变成大黑块、布局被撑烂 | 服务端只发 `Last-Modified`、没有 `Cache-Control`，浏览器复用了**旧 CSS**。修法：给静态资源加 `?v=` 版本号 |
| 图标在无 CSS 时变成 300×150 黑块 | 内联 SVG 只靠 class 提供尺寸和描边。修法：`width`/`height`/`fill`/`stroke` 直接写在标签上兜底 |
| 把打卡项全删光，刷新后它们自己回来了 | "为空就补默认值"缺一个「是否初始化过」标记。修法：加 `initialized` 标志区分"从没用过"与"被删空" |
| 点「完成」后延迟重排（过渡效果）100% 不生效 | 挂起标志设在**写入之后**，而数据层写完会同步派发事件触发刷新。修法：**写入之前**就挂住 |
| 一个脏数据条目让整页白屏 | 读取路径直接返回了存储里的数组，没清洗。修法：读取统一过一层清洗函数，且兜底 id 必须**确定性**（用下标，不用随机值） |
| 详情下拉改了优先级，保存后不生效 | 保存时漏读那个字段 |
| 换肤后主题在"清空数据"时被重置 | 读取偏好的代码写在 `clearAll()` 之后，那时 `meta` 已被删掉 |

## 已知边界

- **数据只在当前浏览器**：换电脑、换浏览器、清缓存都不会跟过去；清了「网站数据」就没了，
  而且**没有服务端备份可恢复**。重要数据请定期「导出 JSON」。
- **同一台电脑 + 同一个浏览器 = 同一份数据**：两个人共用会看到彼此的内容。
  这不是多用户系统，准确说是「**一个页面，各存各的浏览器**」。
- **OCR 依赖从 CDN 加载**（Tesseract.js，版本已锁定）。首次识别需要联网，
  且 CDN 的可达性受网络环境影响；加载失败时会引导改用手动输入，不阻断记账。
- **字体**：大日期首选「霞鹜文楷」。它装在开发者本机，**其他人访问时会回退**到楷体；
  想让所有人一致必须引 webfont（中文字体数 MB 起），本项目没有采用。
